## 方法与判据

**最近邻距离**：每一帧内，对每个人找距离最近的那个人，记下距离。

**TTC（Time To Collision）**：不只是看"现在离得近不近"，而是外推相对运动：

```
相对位置 p = p_B − p_A
相对速度 v = v_B − v_A
最近接近时刻  t_cpa = −(p·v) / |v|²
最近接近距离  d_min = |p + v·t_cpa|
```

若 `t_cpa > 0`（正在接近）**且** `d_min < 0.5 m`（两人身体半径之和，即会撞上），
则 `TTC = t_cpa`；否则这对人根本不会碰撞，不计入。

这比只看间距严格：两人挨得很近但**同向同速**（例如排队），TTC 是无穷大，不算危险。

## 结论

**1. 最近邻间距的分布是"右偏长尾"——绝大多数人保持距离，少数人贴得很近。**
五个场景的中位数都在 **0.74–1.19 m**，而均值被拉到 0.97–1.89 m，
说明分布右边拖着长尾：一小部分人离得特别远（>4 m，落在图外）。
这符合直觉——**人群中"落单"的人比"贴在一起"的人更常见**。
从物理上讲，0.74–1.19 m 正好落在**人际舒适距离**（约 0.45–1.2 m）区间内，
说明数据里的行人间距是有行为意义的，不是随机分布。

**2. 拥挤度排序：students03 (0.74) < zara02 (0.76) < zara01 (0.91) < eth (1.10) < hotel (1.19)。**
这个排序和场景的"人数密度"排序基本一致，但有一个**重要的例外：Hotel 的间距最大（1.19 m）**，
尽管它有 318 人，和 ETH 的 330 人差不多。

原因看 Week 01/02 就知道：**Hotel 里 21% 的人是静止的**，
静止的人散布在大堂各处，彼此离得很远。
而更关键的是：**最多人 ≠ 最拥挤**。真正决定拥挤的是**人在空间上是否重叠**——
按 NN<0.5 m（身体会重叠）的比例看：

- **zara02 = 16.4%、students03 = 12.1%**，这才是真正拥挤的两个场景；
- hotel 只有 4.5%，eth 只有 1.4%。

所以：**zara02 和 students03 是"高接触"场景，hotel 和 eth 是"低接触"场景。**

**3. "人越多 → 间距越近"这个关系被数据明确证实了。**
看 `a3_nn_detail_*.png` 的右图（同帧在场人数 vs 平均最近邻距离），
五个场景**全部是负相关**，拟合斜率都是负的。以 students03 为例，
斜率 −0.016 m/人：在场人数每多 10 个人，平均间距缩短约 0.16 m。
这是**拥挤的定量表达**，也是基本图（q-k-v）的入口——
间距的倒数就是密度。

**4. TTC 的分布形状非常特殊：在短 TTC 处有一条"翘起的尾巴"。**
看 `a3_nn_ttc_all.png` 左下角——注意横轴是**对数**。
分布的主体在 3–10 s（普通人走路时，前面的人会在几秒后才需要避让），
但在 **0.1–1 s 区间明明有一个次峰**，而且这个次峰在 zara02、students03、zara01
上特别突出（曲线在对数轴左端翘起来）。

**这个"翘起的尾巴"就是碰撞即将发生的那部分——是真实避让行为的信号，
不是噪声。** 这也直接连到 Week 05：避让动作就发生在 TTC < 1 s 的时刻。

**5. 危险事件总量：students03 压倒性第一。**
危险对 10478 对·帧，是第二名的 4 倍；TTC < 1 s 有 **777** 对，是第二名的 6 倍。
但要注意**归一化**：students03 有 427 人 / 216 s，本身就是最密的场景。
换成"危险对占全部接近事件的比例"，排序就变了：
**ETH = 26.4% 最高**，students03 = 18.6% 第二。

**ETH 的 TTC<2s 占比最高（26.4%），这是最反直觉的结果。**
ETH 人不多（330）、间距还不小（1.10 m），却是"最容易撞上"的场景。
原因在 Week 02 已经埋了伏笔：**ETH 的人速度快（2.29 m/s，是别人的 2 倍）**。
TTC = 距离 / 相对速度，**速度翻倍 → TTC 减半**。
所以 ETH 的高危险性不是因为挤，而是因为**快**。
这是一个干净的结论：**碰撞风险由"密度 × 速度"共同决定，光看密度会漏掉 ETH 这种"高速低密"的危险场景。**

**6. Hotel 是最"安全"的场景**（TTC<2s 仅 13.1%，TTC<1s 只有 24 对），
因为它速度慢、且大量人静止，根本不会产生相对运动。

**7. 一处需要注意的数据问题：** students03 的 TTC < 1 s 有 777 对，
但其中一部分是**同一个人的 ID 切换**造成的假对子——被遮挡后重新识别成新 ID，
两个"人"位置几乎重合（最小 TTC 0.001 s）。
所以 students03 的绝对数字**偏高**，趋势可靠，量值要打折看。

**8. 一句话总结：** 拥挤要看 NN<0.5m 的比例（zara02 16.4%、students03 12.1% 最挤），
危险要看 TTC < 2 s 的占比（**ETH 26.4% 最高，因为快不是因为它挤**），
而 TTC 分布左端那个"翘起的次峰"就是避让行为的痕迹。
