# A1 轨迹可视化

## 任务

把五个场景里每个人的轨迹画出来，**每个个体一条线**。

## 产出

| 文件 | 说明 |
|------|------|
| `figures/a1_trajectories_all.png` | 五场景总览（**代表图**） |
| `figures/a1_seq_eth.png` | ETH 校园路口 单独大图 |
| `figures/a1_seq_hotel.png` | Hotel 酒店大堂 单独大图 |

## 结论

**1. 轨迹图本身就是场景的"平面图"。** 五张图的形状差异极大，说明场景拓扑完全不同：

- **seq_eth**：轨迹从左侧扇形散开、向右侧收敛，中间有一条明显的水平带。
  这是一条**东西向的走廊/路口**，行人在两侧来回穿越。
- **seq_hotel**：中间有一条**密集的竖直带**，两侧只有稀疏的短线。
  竖直带是酒店大堂的**主通道**；两侧的短线是站着不动或短距离移动的人
  （这一点在 A2 的速度分布里会被验证——hotel 速度有两个峰）。
- **zara01 / zara02**：都是**水平方向的带状人流**，上下边界非常整齐。
  说明这是商业街的人行道，人流被店铺和路缘**约束在一个固定宽度的通道**里。
  zara02 比 zara01 在右边多出一簇斜向轨迹，那是**出入口**位置。
- **students03**：最"满"，轨迹铺满了整个矩形区域，几乎像一个**开放广场**。
  但它上下两端也有明显的水平密集带，说明广场两侧连着走廊。

**2. 轨迹长度分布极不均匀。** 平均轨迹长从 15.6 帧（ETH）到 47.7 帧（zara02），
差了 3 倍。ETH 的轨迹最短，说明行人在路口**快速穿过**就离开画面；
zara02 的轨迹最长，说明商业街上的人**停留时间长、走得慢**。

**3. 平均速度：2.29 / 1.04 / 1.07 / 0.80 / 0.71 m/s。**
ETH 场景的速度是其它场景的 **2 倍以上**。原因有两个：
① 这是露天路口，行人倾向于**快步通过**；② 场景尺度不同
（ETH 视野里 x 方向跨度约 20 m，UCY 约 18 m，量级接近，所以不是尺度问题）。
更可能是**过马路的行为动机**导致——这也是 A2 要展开的点。

**4. 数据有一个需要注意的地方：轨迹会断。**
图上能看到很多孤立的短线段，这不是"人只走了一步"，
而是**目标被遮挡后丢失、重新识别时分配了新 ID**。五个场景都有这个问题，
`students03` 因为人最多（434 个，但实际现场不可能同时有 434 人），
ID 切换最频繁。这会影响 A3 的对子分析（把同一个人当成两个人），
所以后面计算最近邻时会顺带检查这一点。

**5. 一句话总结：** 五张轨迹图 = 五种完全不同的行人空间，
后面 A2–A5 的所有定量指标，都要放在"这个场景长什么样"的背景下才读得懂。
