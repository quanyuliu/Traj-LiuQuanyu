## 行为判据（全部是可量化定义，不是主观描述）

### 成行 / 跟随

A 跟随 B 需同时满足：

1. **A 朝 B 走**：A 的速度向量与 (B−A) 夹角 < 30°（不是并排走）
2. **纵向间距** 0.5–3.0 m（太近是重叠，太远不算跟随）
3. **横向偏移** < 0.6 m（几乎在同一"车道"上）
4. **速度接近**：|v_A − v_B| < 0.4 m/s（不会被甩开也不追尾）
5. **持续 ≥ 3 帧**（约 1.2 s），排除瞬时巧合

### 避让 / 绕行

A 避让 B 需同时满足：

1. **存在接近**：最近距离 < 1.2 m
2. **真的转向**：航向改变 > 8°
3. **转向方向正确**：朝**远离 B** 的一侧转 ← 这条是区分"避让"与"单纯拐弯"的关键
4. **短促**：转向过程 ≤ 5 帧（约 2 s），是反应不是漂移

## 结论

**1. 成行行为确实是"速度对齐"，判据被数据验证了。**
看 `a5_following_all.png` 下方第 4 张图（跟随者速度 vs 被跟随者速度）：
所有点**紧紧贴在 y=x 对角线上**，几乎没有离群点。
这不是判据的循环论证——判据只允许速度差 < 0.4 m/s，
但实际点的散布远比 0.4 m/s 窄，说明**真实队列里的速度对齐程度比判据要求的更严格**。
这条对角线就是"成行"最干净的证据。

同时第 3 张图（纵向间距 vs 横向偏移）显示：横向偏移几乎全部压在
0.6 m 以下并且**密集贴近 0**，说明跟随是**严格的单列队列**，
不是松散的一团人。人走路时会自然排成"一条线"，这个现象被数据抓住了。

**2. 成行的纵向间距中位数约 1.5–2.0 m。**
这个值有物理意义：正常人步速 1.3 m/s、反应时间约 1 s、
加上安全余量，跟随时保持 1.5–2 m 正好是**"看到前面变化后还来得及反应"**的距离。
五个场景的间距分布形状相似（都在 1.2–2.5 m 集中），
说明**跟随时的人间距是一个跨场景稳定的行为常数**，
不随场景类型改变——这是本次分析里最"普适"的一个数字。

**3. 成行频率差异巨大：students03 (2026/千人·分) 是 hotel (33/千人·分) 的 61 倍。**
原因很清楚：
- **students03** 人最多（427）、密度最高，**必然排队**（人多就只能跟着走）；
- **hotel** 的人大量是**静止的**（Week 02 已证实 21% 速度≈0），
  静止的人不参与成行，而且大堂空间宽敞、人分散，很少形成队列。

**成行的前提是"通道被约束 + 人足够多"。** students03 和 zara01/02
都是通道型或广场型空间，天然产生队列；hotel 是开放大堂，不产生。

**4. 避让发生时的最近距离高度一致：0.60–0.71 m（五场景都在这窄区间）。**
这是本次分析**最漂亮的结果之一**。

0.5 m 是两人身体重叠阈值（半径各 0.25 m）。避让的最近距离**系统地
略大于 0.5 m**（多出 0.10–0.21 m）——说明行人是在**"快要碰到之前"
才让开**，让开得不多不少，刚好留出一点余量。
这个 0.6–0.7 m 是**人际关系距离的下限**在运动中的体现。

而且它跨五个场景几乎不变（0.60~0.71），说明这更像是
**人体的生理/心理常数**，而不是场景决定的量。
`students03` 的值最小（0.60），因为它最挤、没有余量。

**5. 避让平均转角 15–22°，students03 最大（21.7°）。**
转一点点就够了——不需要大幅绕行。这也和 Week 02 的发现一致：
横向加速度虽然大于切向，但绝对值很小。

**6. "越靠近 → 转得越多"得到了数据支持。**
看 `a5_avoidance_all.png` 下方第 3 张图：
最近距离 vs 转角呈**负相关**（斜率 +1.3°/m 的拟合实际上是
距离越小转角越大的反比关系）。物理上很合理：
离得近就必须转得急，离得远轻轻一带就够了。

**7. 避让的左右偏好：基本 50/50，没有系统性偏向。**
左转占比分别 55% / 44% / 51% / 45% / 51%，都在 50% 附近波动。
**这是一个"负结果"，但很重要**：它说明**行人没有普遍的右侧通行或左侧避让规则**，
避让方向是**由相对几何位置决定的**（对方在左边就往右让），
而不是社会习俗。如果存在靠右走的习惯，左转占比应该显著偏离 50%。
（ETH 的 55.3% 略微偏左，但样本量下不足以确认，且 ETH 场景只有一条主通道方向。）

**8. 一个需要注意的问题：students03 的事件数被高估了。**
3115 个成行 + 967 个避让，是其它场景的 5–25 倍。
一部分原因是它真的最挤，但**另一部分原因是 ID 切换**
（Week 03 已提到）——一个人被遮挡后重识别成新 ID，
会产生"新人和旧人速度相同、位置一前一后"的假跟随对。
所以 students03 的**趋势可信，绝对数量要打折看**。

**9. 一句话总结：**
成行 = **严格的单列 + 速度贴对角线 + 稳定的 1.5–2 m 间距**，
其出现条件是"通道约束 + 人多"（所以 students03 是 hotel 的 61 倍）；
避让 = **在 0.6–0.7 m 处才发生 + 只转 15–22° + 左右各半无偏好**，
其中"0.6–0.7 m 跨场景几乎不变"说明它是人体尺度的常数，
而"左右各半"说明避让是几何决定的、不是社会习俗。
